# 票 09 · 桌面客户端界面设计

沿用已确认的 E 方向。左栏回答「现在用的是谁」，右栏回答「我正在查看谁，以及上次离开这个账号时还剩多少额度」。同一屏允许这两个名字不同。

## 账号列表

保留浅灰侧栏、白色详情面和蓝色主操作。在约 980 × 660 的客户区内，建议左栏占 260–290 个逻辑像素，为长邮箱、身份和重置提示留出第二行。右侧正文对齐同一左边线，窗口变高时把多出的空间留给快照详情。

搜索和刷新共用一个输入外框。末尾放单色的 14–16 像素回转箭头，按钮命中区至少 32 × 32 像素。鼠标悬停和读屏名称均用「刷新账号列表」。搜索框与图标分别可聚焦，键盘能用空格或 Enter 激活图标。刷新保留搜索词和仍存在的浏览目标；结果来自本机当前登录和存档名单。

| 行状态 | 左栏表现 | 浏览后的右栏操作 |
| --- | --- | --- |
| 已匹配的当前登录 | 置顶。名称旁或第二行常显「当前登录」，以细蓝侧标辅助识别 | 展示身份与上次快照；当前正在使用的身份无需再次切换 |
| 当前登录未保存 | 置顶。「当前登录 · 未保存」及可用邮箱；缺少邮箱时保留文字状态 | 提供「保存当前登录」，其余已存账号可正常浏览与切入 |
| 已登录，旧别名归属不唯一 | 使用核心识别结果。能确认上次切入的别名时置顶它，否则独立展示「当前登录」和可用邮箱 | 已有别名各保留一行，不在界面里猜测要更新哪份存档 |
| 未登录 / 无法读取 | 在列表附近分别显示「未登录」或「无法识别当前登录」 | 已保存的账号仍可浏览；无法读取时保留刷新入口 |
| 正在浏览 | 整行浅蓝底，焦点另有清晰轮廓。仅浏览时当前登录的侧标留在原行 | 右栏同步展示所选账号，明确触发「切换到此账号」才切换 |

当前行始终保留在搜索结果上方。它匹配搜索时仅出现一次。例：当前为「工作」，搜索「课程」，可同时看到当前「工作」和匹配的「课程研究」。零匹配时保留当前行，文字显示「没有匹配的已保存账号」。列表中的别名可省略显示，详情和读屏提供完整名称。虚拟当前行不计入已保存账号数。

## 离开时的额度快照

详情区标题用「上次离开时的额度」或「额度快照」，旁边或下一行给出最近成功采集时间。保留登录类型、账号 ID 和套餐。各限流窗口逐项显示名称、上次记录的剩余比例和本地重置时间，Credits 余额独立呈现。窗口时长使用实际记录。没有读数的字段显示「未知」。

| 数据状态 | 列表提示 | 详情示例 |
| --- | --- | --- |
| 从未取得快照 | 行内留空 | 「尚无额度记录。切离这个账号时会尝试保存。」 |
| 已到记录的重置时间 | 小钟或简短文字「5 小时窗口已到点」；列表内只给简短摘要 | 「5 小时窗口：上次剩余 36% · 已到重置时间」并列出原本的重置时间 |
| 上次耗尽，现已到点 | 同一小钟配有较强对比的文字「上次已用尽 · 已到点」 | 保留「上次剩余 0%」。新快照到来后再更新剩余量 |
| 多窗口时间不同 | 优先展示上次耗尽且已到点的窗口，较窄时用「2 个窗口已到点」 | 分行给各窗口读数和时间，例如周窗口上次剩余 0%，重置时间仍在明天 |
| 最近一次采集失败 | 有到点提示时继续显示它 | 「最近更新失败」及尝试时间；原读数继续带上次成功时间。首次即失败时显示「尚无成功记录」 |
| 缺重置时间 / API 密钥不适用 | 行内留空 | 依数据分别显示「重置时间未知」或相应的登录类型说明 |

到点使用蓝灰色小钟和文字。避免单用红绿色或闪烁，屏幕阅读器获得同等含义。应用打开、从后台回到前台或保持打开跨过重置时间时，根据快照时间重新判断。提醒限于应用内；刷新图标只重读本机状态。额度区没有手动刷新控件。

## 操作反馈

- 切换期间保留 A 的当前身份标记；完成后重新识别实际登录，再让当前标记移向 B。取消或失败时仍以磁盘上实际登录为准。
- A 的登录已保存而额度读取失败时，可以显示「已切换到 B。A 的额度未更新，保留上次记录。」凭据保存失败时，提示「未切换」并给出具体原因。
- 显式保存同一身份时，成功反馈使用新的别名。自动切离保留旧别名。已有未保存的登录按确认规则以邮箱或回退名称入列。

## 独立验收

1. 准备虚构的当前登录 A、目标 B。以键盘浏览 B，在同一屏上辨认置顶 A 的身份标记、B 的选中底色和键盘焦点。搜索 B 或不匹配的关键词，A 仍置顶。
2. 切换虚构活动文件后点搜索框内刷新；分别检查匹配、未保存、未登录。保存或取消后检查完整名称、焦点返回和右栏选择。
3. 准备两个不同时到点的额度窗口，分别检查到点前、到点后、上次耗尽、首次无记录和最后一次失败。核对客户端文案及 CLI 的对应文字。
4. 在窗口最小尺寸和本机显示缩放下检查长邮箱、账号 ID、搜索尾部图标、快照时间和主要操作。用虚构数据截图，由设计角色复核；交付记录区分视觉核对、自动化断言和未实测分支。
