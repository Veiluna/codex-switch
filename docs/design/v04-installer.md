# 票 15 · Windows 安装窗口

沿用已选 E 版桌面端的颜色、中文字形和按钮轮廓。安装窗口只有一项决定：用户核对目标目录后安装或卸载。双击打开安装页，从系统「已安装的应用」进入卸载页。两页与静默入口调用同一安装服务。

## 窗口与控件

- 客户区建议 520 × 330 逻辑像素，正文白底、四边留白 24，字段上下间距 8。下方浅灰操作区有一道细分隔线，按钮靠右、间距 8，边沿与正文对齐。小屏可收紧留白，长路径和长错误信息可换行或滚动，操作区始终可见。
- 页标题使用「安装 Codex Switch」或「卸载 Codex Switch」，微软雅黑 UI 16–18 磅加粗，正文 10 磅。名称只出现在系统标题栏及正文标题等有定位作用的位置。页面用文字传达状态，省去装饰插图。
- 安装位置为有标签、可聚焦和复制的只读字段，显示服务实际解析的完整目录。窗口不显示邮箱、账号名或凭据路径。
- 常规文字色 `#202A34`，次级文字 `#586979`，安装按钮深蓝 `#194D76` 配白字；取消按钮浅底、1 像素 `#80909E` 边框。卸载动作使用暗红 `#914536` 与明确文案。按钮至少 84 × 34 逻辑像素。悬停、按下、禁用和键盘焦点分别可辨；高对比主题采用系统颜色。

## 操作与反馈

| 状态 | 主要信息 | 可用操作 |
| --- | --- | --- |
| 准备安装 | 「为当前 Windows 用户安装桌面端和命令行。」下方展示安装位置。 | 「取消」「安装」。Tab 可浏览目录及按钮，Esc 和关闭窗口均可取消。 |
| 准备卸载 | 「将移除桌面端、命令行及其快捷方式。已保存的账号会保留。」下方展示安装位置。 | 「取消」「卸载」。初始焦点落在取消，直接按 Enter 不会卸载。 |
| 正在执行 | 「正在安装…」或「正在卸载…」。在原窗口显示进度状态。 | 一次操作只提交一次。执行期间停用重复提交和取消。 |
| 安装成功 | 「安装完成」。正文提示「从开始菜单打开 Codex Switch，或在新开的终端输入 codex-switch。」 | 「完成」。Enter、Esc 和关闭按钮均可退出。 |
| 卸载成功 | 「卸载完成」。正文提示「已保存的账号仍保留在本机。」 | 「完成」。 |
| 迁移或其他失败 | 「安装未完成」或「卸载未完成」。展示服务提供的具体原因。命中旧 MSI 时，明确指向 Windows 设置 → 应用 → 已安装的应用，先卸载旧版 Codex Switch，再重试。 | 「关闭」及可重试的操作。卸载重试仍须有意选择；默认焦点落在关闭。 |

## 实窗验收

1. 从真实安装程序打开图形确认页，核对标题、路径、按钮输入顺序和 Esc 取消。取消后文件、环境变量和安装登记不应变化。
2. 从卸载入口打开确认页，直接按 Enter 和按 Esc 分别验证默认取消。分别覆盖执行中、成功和失败，失败文案能读到具体原因。
3. 在受限工作区或较高系统缩放下核对控件边沿、长路径可复制、错误内容可读、两枚按钮完整可见。记录实际检查过的窗口状态、缩放和操作方式。
