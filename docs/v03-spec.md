# 0.3 桌面端和 CLI 重构

## 使用场景

用户在 Codex 中切换多个登录，需要核对目前使用的身份、查看可信的历史额度，并能在桌面和 cmd 中执行相同的账号操作。

## 用户故事与验收

1. 打开客户端时能区分已保存的当前登录、尚未保存的登录和未登录。搜索时仍能看到置顶的当前登录，同时可以浏览另一个账号。
2. 在外部完成登录后，点击搜索框末端的小刷新图标可以重新识别身份。浏览、搜索和刷新只读取本机数据。
3. 想切换到另一个账号时，先授权退出正在运行的桌面端。若正常退出失败，单独决定是否强制关闭。
4. 退出后先保存原登录的最新凭据，成功后采集其额度，再切换目标。凭据保存失败时保留原登录。额度读取失败时保留上次成功值及时间，记录本次失败，继续切换。
5. 首次保存默认以邮箱命名。同一身份更新原记录；不同身份的邮箱重名时区分工作区或短 ID。自动保存保留用户已有别名。身份有歧义时保留可核对的记录。
6. 详情可见账号 ID、邮箱、套餐、每个可识别额度窗口的剩余量、快照和重置时间。所有已到重置点的窗口显示文字提示，上次已耗尽的窗口加强提示。
7. 可以查看、保存、切换和删除本地存档。删除之前确认目标，删除仅影响本地具名存档。
8. 在 cmd 中直接运行命令可用方向键选账号。脚本通过显式子命令和退出码调用，单独授权正常和强制关闭。
9. 可使用两个独立的便携 EXE，或为当前用户安装 MSI 后，从开始菜单和新终端使用两个入口。

## 实施与验证

两个入口共用一个账号服务。UI 设计、UI 实现和功能实现各自独立。用虚构凭据通过服务、桌面窗口及 CLI 验收；隔离安装验证安装、升级和卸载。在线账号注册、系统通知及后台轮询不在本版范围。
