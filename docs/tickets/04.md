## 实现与接口

`Desktop.ps1` 是唯一桌面守卫来源。当前用户的 `Get-AppxPackage OpenAI.Codex` 必须匹配 `OpenAI.Codex_2p2nqsd0c76g0`，manifest 必须有 `App`，入口必须是 `app/ChatGPT.exe`。进程同时满足当前 session、安装入口的完整路径、原生 `GetPackageFamilyName` 后才列为桌面进程。相同 exe 路径的辅助进程也必须全部退出；同包的 `app/resources/codex.exe` 是 CLI/服务，不关闭、不阻塞切换。同包桌面路径过期、身份或安装无法确认时保守失败，同名但已确认来自无关路径/包的程序不受影响。

`Invoke-DesktopAccountSwitch -Root -Name -Owner` 为 GUI 默认回调。只对最初发现的进程快照发关闭请求；每次动作重查 PID、启动时间、session、路径和包身份，持有句柄再操作，禁止杀进程树或按进程名批量关闭。正常退出超时后展示第二次确认；二次取消即停止。写入仍走 `Invoke-SwitchAccount -BeforeWriteGuard`，在文件锁内重新确认桌面全部退出，回调只返回单一 Boolean。第一次确认期间用户自己退出、工具未实际发出有效关闭请求时，完成切换后保持关闭。

CLI 永不自动关闭任何进程，只使用同一只读桌面守卫。GUI 与 CLI 的默认 Root 都遵循 `CODEX_HOME`，未设置则使用 `%USERPROFILE%/.codex`。

成功切换且本次工具确实发出了退出/强制请求，才按已验证 AUMID 重开，并轮询真实桌面进程是否出现。切换失败不重开；重开无法确认时结果为 `Success=true, Code=RestartFailed`，界面明确显示“已切换”并提示手动打开。长错误消息同时弹窗，避免状态栏截断。取消、桌面未知、仍运行、文件切换失败、重启失败均有独立结果。

## 文档依据

Context7 `/microsoftdocs/windows-powershell-docs` 核实：`Get-AppxPackage` 默认当前用户；`Get-AppxPackageManifest -Package <PackageFullName>` 可读取 application id。`/dotnet/docs` 对进程生命周期的检索未提供足够成员细节，补充 Microsoft 官方 API 文档：

- [GetPackageFamilyName](https://learn.microsoft.com/en-us/windows/win32/api/appmodel/nf-appmodel-getpackagefamilyname)：以进程句柄读取包 family，区分无包身份与查询错误。
- [Process.CloseMainWindow](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.process.closemainwindow)：请求主窗口关闭，返回是否成功发出消息。
- [Process.Kill](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.process.kill)：终止当前进程；等待与终止分开处理。
- [ShowWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindow)：仅用于受控屏幕外测试窗口，隐藏启动后显式建立可关闭的主窗口。
