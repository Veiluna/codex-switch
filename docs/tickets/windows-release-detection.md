# Windows 发行物检出与修复验收

v0.4.0 的 `codex-switch.exe` 和 `installer.exe` 在 Windows Defender 中被隔离，检测名为 `Trojan:Win32/Sabsik.FL.A!ml`。同版 npm 附件包含这两个文件。便携桌面端单文件扫描未检出。检测名没有指出触发判定的源码位置。

## 验收范围

- CLI 菜单应只允许切换到用户看到的账号存档。同一名称被替换后，切换须在关闭客户端、采集额度或写活动凭据之前停止。命令行显式按名称切换仍按调用时的存档处理。
- 安装器回滚只可删除本次事务发布的文件。目标被其他文件占用时，保留该文件及可恢复的旧备份。卸载完成后应终止文件操作，避免后台清理按路径删除归属已无法核验的文件。
- 发行流程在封装可执行文件和形成对外附件之前验证构建产物。检测异常、产物缺失或被修复时应停止出包。

同一版的 25 项构建输入已与本地源码核对，其中 24 项的字节摘要直接一致，余下 1 项仅有 LF/CRLF 差异。这一核对只能追溯构建输入。以上行为修复、功能回归和针对最终 EXE 的 Defender 验收分别记录。

## 回归证据

- 用虚构账号运行 `Test-AccountService.ps1`、`Test-NativeCli.ps1` 和 `Test-NativeUi.ps1`，分别通过 51、48 和 52 项。独立评审核对了菜单 Enter 传入的存档摘要及锁内比较的位置。
- `Test-ReleasePayload.ps1` 的 14 项夹具检查通过。本机 Defender 对普通文本和项目 XML 清单均给出明确的无威胁结果。`Test-NpmDistribution.ps1` 使用独立的无账号测试程序验证离线安装、入口及参数转发，通过。
- Context7 `/microsoftdocs/defender-docs` 确认命令行扫描返回 0 也可能表示已完成修复。出包检查还要求目标路径的明确无威胁结果，以及扫描前后相同的文件摘要。遇到未识别的结果会中止。
- 安装器的 130 项隔离断言通过，覆盖卸载、快速重装、外来文件占用目标、保留旧备份，以及打开文件后核验链接属性。独立评审复核通过。期间一次测试遇到短暂的文件占用，未确定占用进程；后续完整测试和正式安装器生命周期测试均通过。
- 2026-11-21 在本机从核对过的源码构建 0.4.1。Defender 平台 `4.18.26100.4`、安全情报 `1.463.390.0`、实时防护开启。桌面端、CLI、卸载程序和最终安装器均获得明确的无威胁结果。该结果仅针对本次构建及本机检测环境，旧版告警的触发原因仍未知。
- 同一批产物通过 `Test-NativeDistribution.ps1`、`Test-SetupEntry.ps1`、`Test-Installer.ps1` 和真实 npm 入口测试。安装器在隔离的文件和注册表目录中重复安装两次再卸载，并核对快捷方式、登记项及 PATH。最终 tgz 内两个 EXE 均与交付目录中的对应文件逐项核对 SHA-256。
- 本地交付在 `dist/v0.4.1/`，附 `SHA256SUMS.txt`。未向微软准备或提交样本。
