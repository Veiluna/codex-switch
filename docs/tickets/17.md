# 票 17 · npm 与 npx 分发

提供可安装及一次运行的 Windows x64 包。包内携带原生 CLI 和同版安装器；验证全局安装、npx、参数转发、返回码和 npm 安装器入口。无账号数据、无需安装时下载 EXE。

前置票为 14。

## 实现

- npm 包为 `@veiluna/codex-switch@0.4.0`，仅限 Windows x64，Node.js >=18；无依赖、无 npm 生命周期脚本、无安装时下载。
- `codex-switch` 直接调用包内 `native/codex-switch.exe`；`codex-switch-install` 调用包内 `native/installer.exe`。原样转发参数，继承 stdio，同步返回原生退出码；启动失败返回非零。
- `npm/Pack.ps1 -Version 0.4.0 -DistPath <产物目录> [-OutputDirectory <输出目录>]` 可由 Windows PowerShell 5.1 调用。默认输出到 DistPath，产物为 `veiluna-codex-switch-0.4.0.tgz`。
- 打包前要求两个 EXE 均为 x64 PE、FileVersion 均为 `0.4.0.0`。使用唯一临时 stage，只复制明确列出的七个文件，并核对 `npm pack --json` 的完整文件列表；不遍历项目、账号目录或产物目录。

## 文档核实

- Context7 `/npm/cli/v11.19.1`：多个 bin 时，`npm exec`/`npx` 选择与未加 scope 包名相同的 `codex-switch`；安装器需使用显式 bin 名。`files` allowlist 以文件级路径声明，另用隔离 stage 规避 npm 默认附带 README/LICENSE 等项目文件。
- Context7 `/nodejs/node/v24.22.2`：`spawnSync(exe, args, {stdio:'inherit', shell:false})` 共享标准流，由 Node 执行 Windows 参数引号处理；`status` 为原生退出码，启动异常通过 `error` 区分。
