# 06　E 版账号切换窗口

## 交互约定

- 左侧可按名称查找存档。单击或用方向键选中账号，右侧显示将要切换的目标。
- 点击右侧切换按钮或在列表内按 Enter，才开始切换。桌面端运行时，用户仍可在退出确认框中取消。
- 保存当前登录时原位显示命名错误。保存成功后，清除搜索条件并选中新名称。
- 主窗口、保存窗口和退出确认以文字为主，省去装饰图标。

## 验收范围

使用临时目录和虚构凭据验证选择、搜索、保存、切换、备份及重开后的名单。从独立解压目录重复核心流程，核对 ZIP 里实际运行的代码。

## 验收结果

- 加入新断言后，旧 ZIP 在「保存后预览新别名」处按预期失败。
- Windows PowerShell 5.1 下，`Test-Window`、`Test-Switch`、`Test-WindowSmoke`、`Test-Save`、`Test-Desktop` 和 `Test-Distribution` 六组测试全部通过。烟测从正式启动器打开有账号和空列表两种窗口。鼠标与键盘分支以控件事件验证。
- 从新版 ZIP 解压并打开实际窗口，使用两个虚构账号验证了保存、筛选、选择、明确切换、备份和重复切换。选择与搜索期间，活动文件字节保持一致。分发测试注入桌面端已关闭状态；退出和重开测试使用受控替身进程。
- 已查看虚构账号主窗及保存弹窗截图。独立代码评审通过。12 个脚本的语法与 UTF-8 BOM 检查通过。PSScriptAnalyzer 1.25.0 对六个运行脚本报告 0 个错误、10 个警告，涉及参数、自动变量、空 catch、ShouldProcess 和命名单复数。高 DPI 实屏显示仍待验证。
- 本地 ZIP 共 10 个文件，与工作树逐项比对 SHA-256 一致。ZIP 大小为 34,420 字节，SHA-256 为 `aeb772e33da13fd54db6f53e663c3344dd6cb70733ebc52b8515f246dc2b18d2`。
