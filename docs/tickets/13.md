# 票 13 · 构建、安装与集成验收

| 项目 | 约定 |
| --- | --- |
| 负责人 | 主智能体 |

分别生成 GUI 和 CLI 两个便携 EXE，并将两者加入当前用户的 MSI。

## 验收

验证两个 EXE 内嵌同一共享核心，与 MSI 内实际文件一致；执行虚构账号测试、独立视觉复核及隔离安装、升级、卸载测试。

## 分发验证记录

- `Test-Installer.ps1` 在宿主 Windows 上以独立产品完成单程序旧版安装、双程序新版升级、阻止降级和卸载。使用专用的用户环境变量验证追加与移除安装目录，并核对原值、额外用户文件和虚构的活动凭据均保留。
- `Test-NativeDistribution.ps1` 从每个便携程序读出同一份核心程序集，逐字节核对嵌入脚本和 MSI 内两个文件。构建清单包含全部源输入、版本和产物 SHA-256。
- 两个评审者分别检查规范与规格。评审发现额度采集期间桌面可能重启、活动凭据暂时不可读时的浏览状态，以及 CLI 未强化已耗尽窗口提示，这些发现交回对应实现票验证。
- Windows Installer 的 PATH 追加使用 `[~];[INSTALLFOLDER]`。文档依据为 Context7 `/websites/learn_microsoft_en-us_windows_win32_msi`。共享程序集采用 .NET Framework 的嵌入资源与程序集解析接口，文档依据为 `/websites/learn_microsoft_en-us_dotnet_framework`。
- 修复后，核心原有 36 项及另设的评审回归组均通过。桌面 52 项检查及空目录、已保存、当前已保存、当前未知、活动凭据损坏五种真实程序启动均通过。CLI 52 项含真实隐藏控制台的方向键和 Esc 注入，并核对虚构凭据未发生变化。在线额度未使用个人账号实测。
