# v0.4.3 验收记录

版本规格登记在 [GitHub #16](https://github.com/Veiluna/codex-switch/issues/16)。子票分别跟踪[额度展示 #17](https://github.com/Veiluna/codex-switch/issues/17)、[切换工作空间 #18](https://github.com/Veiluna/codex-switch/issues/18) 和[桌面交互 #19](https://github.com/Veiluna/codex-switch/issues/19)。

- 桌面和 CLI 共用额度格式。测试覆盖服务端主次顺序互换、缺失窗口、旧快照、剩余 0%、超过 24 小时、最后不足一分钟和到点。刷新界面只读取本地快照。
- 桌面测试记录列表失效区域、选区及焦点。相同内容的计时器更新没有触发列表重绘，到点只更新对应行。界面回归还覆盖正常关闭零弹窗、关闭超时后只询问一次。[虚构账号详情示例](../design/v043-details.png)
- 同用户跨空间的受控进程测试核对原进程保留、先保存离开快照、文件并发冲突和本机身份确认。只有读到活动登录的目标用户和工作空间才显示成功。当前 Windows 客户端要求在 Codex 内选择空间；真实账号切换未实测。[客户端版本、接口与测试记录](18-workspace.md)
- 独立评审发现的两个问题均已补回归：API key 附带旧身份字段时不能误确认，正常退出期间被替换的目标存档不能生效。

Windows 分发通过源码与嵌入文件摘要比对、五种虚构登录状态的桌面启动测试、隔离安装和卸载、真实 npm 包的离线入口测试。发布清单包含桌面端、CLI、安装器、npm 包的 SHA-256。
