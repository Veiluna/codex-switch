# 08　Windows 可执行程序、账号删除与额度详情

## 交付约定

- 桌面界面用 C# 和 WinForms 实现。直接运行 EXE 或使用当前用户安装包，继续识别旧存档。
- 点击账号先预览。查看账号 ID、登录类型与可用的套餐信息，按需查询额度。窗口按账号显示剩余比例与本地重置时间；不能确认归属、接口未返回、网络失败或登录过期时，说明具体状态。
- 删除针对所选本地别名。确认框中显示名称，默认取消；确认后重新核对存档快照，保护活动登录与其他账号。
- 继续复用首版已测试的保存、退出、备份、切换和恢复逻辑。
- 构建用于免安装运行的 EXE 和标准 Windows 安装包。在隔离目录中验证安装、升级与卸载，核对卸载前后的虚构账号数据。

## 0.2.0 验收结果

- C# 桌面程序在空目录和含两个虚构账号的目录中均通过真实 EXE 启动测试。用 UI Automation 核对进程、主窗口、详情和按钮。修复了启动时重建文本框句柄导致的异常，以及高 DPI 下字号和行高不同步造成的裁切。[实窗截图](../desktop.png)
- 账号、删除与额度的 37 项合成检查全部通过。包含快照过期、文件锁、同名不同后缀、硬链接、目录改名、API 密钥、不支持的登录类型、剩余比例边界和本地重置时间。23 项原生 UI 与嵌入脚本测试通过。[数据来源与测试边界](../native-account-data.md)
- 原脚本的保存、切换、备份、恢复与桌面进程测试通过。所有账号均使用虚构凭据，联网额度没有使用个人账号实测。
- 独立安装夹具完成安装、升级、降级拦截和卸载，核对了开始菜单、应用登记及用户文件保留。最终分发测试逐项核对源码、嵌入资源与构建记录，并确认 MSI 内含的程序与便携 EXE 字节相同。[安装和构建依据](../../installer/README.md)
- 两个本地构建产物均未签名。EXE 的 SHA-256 为 `9b77fd712dee6b91f5b0b418fa3e7cf32912c87d80d7d44e83df82722c151c18`；MSI 为 `256846e7aa1437feead3a8363fee7e852e805eabb036b2ea57e68279c4529571`。
