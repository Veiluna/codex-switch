# 票 14 · 原生静默安装和卸载

使用同一个自研 installer.exe install --quiet 或 uninstall --quiet，为当前用户管理桌面和 CLI。同步返回退出码，创建开始菜单快捷方式、PATH 和 Windows 应用列表项。卸载只处理安装器拥有的内容。

前置票为 无。

## 实施证据

- `installer/native/InstallService.cs` 提供默认构造器、`DirectoryPath`、`Install()`、`Uninstall()`，C# 5 / .NET Framework 4.8；仅 `Install()` 加载 `Payload.CodexSwitch.exe`、`Payload.codex-switch.exe`、`Payload.uninstall.exe`。
- 默认产品目录为 `%LOCALAPPDATA%\Programs\CodexSwitch`，开始菜单为当前用户 `Programs\Codex Switch`，卸载 helper 缓存在 `%LOCALAPPDATA%\CodexSwitch\Setup`。卸载登记直接指向该 helper，静默调用同步返回正式程序、快捷方式、PATH 和应用登记的操作结果。
- `UninstallHost.cs` 的入口为 `CodexSwitch.Setup.UninstallHost`，与服务及图形入口 `SetupForm.cs` 一起编译为 `uninstall.exe`（引用 `System.dll`、`System.Core.dll`、`System.Xml.dll`、`Microsoft.CSharp.dll`、`System.Windows.Forms.dll`），先编译此文件，再嵌入安装器。图形调用 `SetupForm.Run(service, true)`；`--quiet` 无界面，退出码为成功 0、失败 1、参数错误 2。
- 运行中的 helper 在事务内先改名为本次唯一缓存文件；正式产品卸载成功后，使用 Windows 自带 PowerShell 在宿主退出后校验 SHA-256，只删除该唯一旧文件及空缓存目录，不递归、不读取外部删除路径。快速重装生成的新 `uninstall.exe` 不在清理目标内。清理进程无法启动时可能保留这一旧缓存文件，正式卸载结果仍已同步提交。
- 保留原始用户 PATH 文本和 `REG_SZ` / `REG_EXPAND_SZ` 类型；预先存在的等价目录不认领，用户新加的其他项不删除。未知文件、账号存档、其他注册表字段均不删除。
- 文档核对：Context7 `/websites/learn_microsoft_en-us_dotnet_framework` 未覆盖原始环境值细节，回退核对 Microsoft Learn `RegistryKey.GetValue` 与 `FileShare` 文档，确认 `DoNotExpandEnvironmentNames` 读取原始文本、`FileShare.Delete` 允许持锁移动和删除；不使用 MSI。
- 验证：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-InstallerService.ps1`，90 条隔离断言通过。测试以专用目录和 `HKCU\Software\CodexSwitch\InstallerServiceTests\<GUID>` 代替真实程序、环境和应用登记；未安装真实用户产品。证据目录：`tests/.tmp-native-installer-f1d84baf2eda4d5d93957988f356d65f`。
