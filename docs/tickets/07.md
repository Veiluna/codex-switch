# 07　统一 E 版各窗口的控件与反馈

| 窗口 | 用户需要辨认的操作 |
| --- | --- |
| 账号列表与详情 | 看清正在搜索的输入框、选中的账号和可执行的切换按钮。没有匹配项时，切换按钮应禁用。 |
| 保存当前登录 | 清楚区分保存和取消。名称有误时，保留输入，并在输入框附近显示原因。 |
| 正常退出确认 | 显示目标别名和退出后的行为；默认选中取消，明确操作后才退出。 |
| 强制关闭确认 | 说明中断任务的后果；使用专门的危险操作文字与颜色，并保留取消。 |
| 切换结果提示 | 在同一个窗口读完结果和下一步，关闭提示即可返回。 |

### 设计依据

沿用用户选定的 E 双栏方案。依照 ui-ux-pro-max 的可见焦点指南检查输入框和按钮，依照 design-taste-frontend 统一按钮轮廓、对齐和每个窗口的主要操作。保存表单参考 Cult UI 的 Popover Form，将紧凑的字段、错误提示和操作区落实到 Windows 原生控件。按 huashu-design 的看图打磨流程检查实窗截图。[逐窗口截图与修改记录](../../design-demos/polish-log.md)

### 验收结果

- 先在旧实现验证主按钮边框和新增确认窗的测试会失败。旧 ZIP 也未通过新增样式脚本的文件清单检查。
- Windows PowerShell 5.1 上七组测试全部通过。用虚构账号从 ZIP 验证保存、预览和切换。正常退出和强制关闭的流程测试使用测试进程。17 个真实弹窗场景覆盖有无父窗口、默认回车、Esc、叉号、取消、明确操作及滚动到长结果末尾。
- 对照两轮原生窗口截图检查了按钮、输入框、错误区和各确认框。在 1.5 倍模拟缩放后复核输入框位置。高对比模式使用系统按钮样式，尚未在实机切换高对比主题或跨 DPI 显示器验证。
- Context7 使用 `/websites/learn_microsoft_en-us_dotnet_desktop_winforms`。为避免长英文别名被测成单行，正文高度依据原生文本框的视觉行号计算。[微软 GetLineFromCharIndex 文档](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.textboxbase.getlinefromcharindex)
- 独立评审后修正了高对比按钮的前景与背景搭配。PSScriptAnalyzer 对七个运行脚本报告 0 个错误、13 个警告。本地 ZIP 共 11 个文件，均与工作树逐项核对。ZIP 的 SHA-256 为 `bc608dd11c72412c7d4d210288b4a01e00908e43439217d11921c0fc49df135a`。
