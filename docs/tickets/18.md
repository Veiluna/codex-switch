# 票 18 · 构建和发布验收

从源码生成 Windows 便携 EXE、自研 installer.exe、npm tarball 和校验清单，验证各入口和生命周期后发布 GitHub。用户已确认本版通过 GitHub 附件提供 npm/npx 的安装来源，公共注册表发布延至 npm 登录后。

前置票为 15、16、17。

## 发布验收

- 安装服务 90 项隔离断言通过。独立评审发现备份清理异常可能触发部分回滚，修复后注入清理失败，复核确认文件、PATH、卸载登记保持一致。
- 正式 installer.exe 进程通过帮助、错误参数、安装页取消和卸载页取消测试。正式程序集内的安装服务在专用目录和 HKCU 夹具中安装两次再卸载，核对了两个 EXE、真实快捷方式和 PATH 原值。图形流程另通过 30 项控件断言和消息循环测试。
- 正式 npm tarball 通过 Windows x64 隔离安装和两个入口的执行测试。分发检查核对了编译输入、嵌入资源与发布附件的 SHA-256。
- 真实显示器检查范围为 96 DPI。高缩放布局使用 150% 注入测试。旧 MSI 迁移通过登记夹具验证。测试未安装用户真实产品，未接触账号存档。
