# 票 15 · 图形安装界面

独立设计和实现双击打开的中文安装、取消、结果和图形卸载流程。复用静默入口的安装服务；覆盖键盘操作与实际窗口。

前置票为 14。设计见 `docs/design/v04-installer.md`。

## 实现

- `installer/native/SetupForm.cs` 提供 `CodexSwitch.Setup.SetupForm.Run(InstallService service, bool uninstall)`；只调用服务的 `DirectoryPath`、`Install()` 和 `Uninstall()`。
- 白色正文、浅灰操作区和深蓝安装按钮沿用桌面 E 方向，卸载及错误使用暗红。目录为可聚焦、可全选复制的只读多行字段，长错误可滚动。高对比模式采用系统色。
- 退出码：成功 `0`，服务失败 `1`，取消或未执行即退出 `3`。`2` 留给入口的命令参数错误。
- 卸载初始焦点及 Enter 默认均为取消；失败后默认关闭，重试卸载需要明确选择。执行期间关闭、Esc、取消及重复提交均被阻止，服务在 STA 后台线程运行，结果回到 UI 线程显示。成功后完成按钮位于操作区右侧。

## 验证证据

`powershell -NoProfile -ExecutionPolicy Bypass -File tests/Test-SetupUi.ps1` 已通过：真实 `Application.Run` 消息循环取消测试（1 项）和隔离 UI 测试 30 项断言。测试单独编译同名的受控 `InstallService` 桩，不包含真实安装服务，不操作安装目录、PATH、卸载登记或账号数据。

覆盖目录完整选择、Tab 顺序、Esc 取消、卸载默认 Enter 取消、服务调用一次、执行中禁用及关闭保护、安装成功、具体旧 MSI 错误、长错误滚动到底、失败显式重试卸载、卸载成功，以及最小窗口按钮边沿。所有服务输入与截图数据为虚构。

本机实际显示 DPI 为 96。150% 验证调用 `Form.Scale(1.5, 1.5)` 检查控件几何布局，未更改系统缩放，不能作为实际 150% 显示器或跨屏 DPI 迁移的实测证据。安装程序的实际服务整合、真实装机取消副作用和高对比系统主题切换由整合验收补充。

## 文档核对

- Context7 `/websites/learn_microsoft_en-us_dotnet_desktop_winforms`：自动缩放使用 `AutoScaleDimensions` 与运行时尺寸的比例，不应混用 Font 与 DPI 模式；窗口统一采用 DPI 模式、96 基准，沿用工程 manifest 的 DPI 行为。
- Context7 未返回 RichTextBox 截图限制，改查官方文档：[DrawToBitmap](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.control.drawtobitmap) 仅支持 RichTextBox 边框，[PrintWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-printwindow) 可取得窗口自身渲染。本测试据此采用 PrintWindow，避免错误正文在验收截图中消失。
