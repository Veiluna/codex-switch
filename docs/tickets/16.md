# 票 16 · 升级与旧版迁移

重复安装、升级或失败后重试保持一致。识别 0.3 MSI 登记并提示先卸载，保护现有存档和其他软件的 PATH。

前置票为 14。

## 实施证据

- 使用具版本和固定文件 SHA-256 的归属记录，首次安装拒绝覆盖外来同名文件；升级/卸载对已改动文件拒绝操作，未知文件保持原样。重复安装不重复追加 PATH，允许升级，拒绝较旧版本。
- 检测历史 `HKCU\Software\CodexSwitch\Installer\InstallDirectory` MSI 标记，并检测 HKCU/HKLM 的 32/64 位 Windows Installer 应用登记，提示先从 Windows 已安装的应用移除旧版。该判断在写入文件前完成。
- 按当前用户串行化安装操作；在移动任何文件前持有所有受管文件锁，运行中的产品导致预检失败，原安装保持不变。拒绝链接/重解析点、损坏的归属清单、过长路径和包含 PATH 分隔符的根目录。
- 提交前发生文件、PATH 或应用登记错误时恢复原程序、原始 PATH 及登记；提交点之后仅做旧备份清理，清理异常保留唯一旧备份，不回滚已提交的登记或程序，避免账实不一致。
- `tests/Test-InstallerService.ps1` 的 90 条隔离断言覆盖重复安装、升级、降级拒绝、三个阶段的安装/升级/卸载失败回滚、提交后清理失败、旧 MSI 标记、真实运行夹具、并发、实际 junction、恶意清单路径、未知文件及注册表字段保留、卸载 helper 同步结果和快速重装缓存清理。
- 该测试不修改真实安装或真实 PATH，不触及账号数据；断电/进程被强制终止的跨进程恢复、受限域策略下缓存清理、真实旧 MSI 到新版本的实机迁移不属于本次隔离测试证据。
