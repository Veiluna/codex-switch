## 发布候选验证

缺包时分发测试先失败。生成 ZIP 后，Windows PowerShell 5.1 下的 `Test-Window`、`Test-WindowSmoke`、`Test-Save`、`Test-Switch`、`Test-Desktop` 和 `Test-Distribution` 六组测试均以 0 退出。运行包的 SHA-256 为 `82bfd2a104fab29f12a14d7738bff3486435305f20b8c0e48e07bc4a5577e5ed`。

独立评审核对了 ZIP 内全部十个文件及其哈希，并从解压目录重新运行分发测试。分发测试注入「桌面端已关闭」的状态。原生窗口启动、受控进程退出与重开、真实客户端只读识别的证据分别在票 01 和 04。

PSScriptAnalyzer 1.25.0 对六个运行脚本报告 0 个错误、13 个警告，涉及自动变量名称、空 catch、参数使用、ShouldProcess 和命名单复数。PowerShell 5.1 的解析检查通过。

另从全新解压目录直接运行两个正式启动器。图形入口的有账号与空列表场景均通过，命令行入口成功列出指定虚构账号。
