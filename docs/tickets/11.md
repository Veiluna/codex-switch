## 验收

实窗验证刷新重读身份、当前账号只置顶一次、浏览其他账号时保留高亮、搜索无匹配、键盘操作和切换确认。

## 实现与证据

- `MainForm` 仅通过 `IDesktopAccounts` / `AccountService` 读取列表和执行保存、删除、切换；不直接读取账号文件或联网。当前行固定置顶，搜索保留且不重复，选中状态与当前身份分开。
- 搜索框内使用 GDI 刷新图标；保留原生按钮 caption 供 Framework MSAA/UIA 代理读取，绘制时只显示图标。无手动额度查询按钮。
- 历史快照显示最近成功时间与失败状态；所有有可信重置时间的窗口使用内存中数据按秒和回前台时重算。上次耗尽且到点较醒目，不声称额度已恢复。
- 切换在专用 STA 线程调用服务，确认通过 `Control.Invoke` 回到 UI 线程；`Close` / `Force` 独立对话框均默认取消。后台等待期间消息循环可继续处理消息。
- `tests/Test-NativeUi.ps1`：46 项假服务控件断言通过，覆盖搜索/当前置顶/去重、提醒不增加 List 调用、删除快照参数、取消无保存、保存错误与重试、两段确认、STA 与 UI 回调、最小窗口控件边界。
- 独立编译当前源后执行 `tests/Test-NativeStartup.ps1`：`empty` / `saved` / `current` / `unknown` 四种全假账号场景通过，验证真实进程 PID、标题、UIA 控件、刷新读屏名称及稳定消息循环。
- `docs/design/v03-ui-synthetic.png`：真实最小客户区 940 × 650、当前显示器 250% 缩放，仅虚构账号。票 09 设计角色独立打开并复核通过；主操作、刷新入口及快照区未裁切。截图需设置 `CODEX_SWITCH_UI_ARTIFACT` 才生成，不是默认测试副作用。
- Context7：`/websites/learn_microsoft_en-us_dotnet_desktop_winforms`，跨线程控件访问使用 `Control.Invoke` / `BeginInvoke`，当前 Framework 目标不采用 .NET 9 `InvokeAsync`。

未实测分支：系统高对比主题切换、多显示器移动；仅保留系统颜色及焦点轮廓适配，未以自动化断言冒充这些实机测试。
