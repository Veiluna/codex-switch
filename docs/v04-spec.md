# Windows 自研安装程序

## 使用者目标

Windows x64 用户可以双击一个离线安装程序，或从 cmd、PowerShell、部署脚本运行同一个程序，安装桌面端与原生命令行。新版本的构建、安装和卸载均由项目自己的代码完成。

## 用户故事

1. 双击 installer.exe 后可核对安装位置、确认安装、看到结果，并能取消。
2. 在终端运行 installer.exe 的静默安装参数可以完成同一操作并取得确定的退出码。
3. 当前用户可以从开始菜单启动桌面端，从新开终端运行 codex-switch。
4. 用户可以重复执行安装、升级，或从 Windows 应用列表及命令行卸载。卸载保留账号存档和其他用户文件。
5. 已安装 0.3 MSI 的用户可以看到明确的迁移指引，避免旧卸载项误删新程序。
6. 下载发布附件后可离线安装，GitHub Release 列出校验值。

## 实施决策

使用仓库已有的 C# 工具链编写每用户安装器，嵌入客户端和 CLI。图形与静默入口共享安装逻辑。自研安装包不包裹 MSI。将旧 MSI 作为历史安装状态单独检测，默认提示从 Windows 已安装的应用移除旧版，再继续安装。沿用现有账号目录。同时提供 npm/npx 分发及 GitHub tarball。

## 验收边界

使用编译得到的正式安装程序，核对双击和静默入口、返回码、程序字节、快捷方式、用户 PATH、卸载登记、重复安装、升级及回退。使用隔离夹具验证旧版迁移和账号数据保留。UI 设计与实现分别由独立角色执行，安装服务另行实现。
