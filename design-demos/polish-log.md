# 界面选稿验证

## 正式 Windows 窗口的控件复核

沿用 E。第一轮在真窗中检查了搜索、保存错误以及三个消息弹窗。输入外框比按钮两端各宽一段，确认框重复询问同一件事，较长的无空格名称还可能超出消息正文。

第二轮把输入外框与操作按钮外沿对齐，增大保存错误与按钮间距。确认框先给目标账号，再说明对正在运行任务的影响。强制关闭使用独立的危险按钮。实际窗口的原生文本区负责计算换行，超长结果支持滚动到最后一个字符。

比较基线为正式 Windows 版，所有原型使用内存中的示例账号。三个主稿均在浏览器中以 900×620 和 375×812 渲染，最终页宽与页高分别等于视口尺寸。

检查了三版的命名、重名、取消、切换和页面刷新后的示例状态。B 的再次切换仍会要求确认；C 模拟正常退出超时后可以取消，也可二次确认强制分支。六格缩略图内容检查全部通过。三份单稿均通过设计文字与模板装饰检查。跨稿配色比较认为 A 和 C 均为高明度底色；保留两者，供用户直接比较整行清单和图形卡册的操作差异。桌面应用原型按真实任务与窗口尺寸验收。

正式应用尚待选稿。设计只用自绘几何、系统字体和表单控件；参考板来自当前窗口和微软 PowerToys 文档。预览不会加载在线组件、读取凭据或控制桌面程序。
